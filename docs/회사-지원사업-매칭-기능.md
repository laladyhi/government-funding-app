# 회사-지원사업 매칭 기능

AI나 외부 API 없이, 저장된 회사 정보와 지원사업 공고를 규칙(키워드 대조·
날짜 계산)으로 비교해 "적합 가능성 높음 / 검토 필요 / 조건 불일치"로
분류해 보여주는 기능입니다.

## 사용 방법

### 방법 1 — 목록 화면에서 바로 입력 (`/programs`)

목록 화면 왼쪽에 "내 회사 맞춤 찾기" 패널이 있습니다. 여기에 회사 정보를
입력하고 "저장하고 맞춤 결과 보기"를 누르면:

- 저장된 회사 정보를 기준으로 오른쪽 목록이 자동으로 "적합 가능성
  높음"·"검토 필요" 공고 위주로 다시 정렬됩니다.
- "전체 사업 보기" / "맞춤 사업만 보기" 버튼으로 전환할 수 있습니다.
- 회사 정보를 한 번 저장해 두면, 이후 `/programs`에 다시 들어올 때도
  가장 최근에 수정한 회사 기준으로 자동 적용됩니다(직접 "전체 사업
  보기"를 누르지 않는 한).

### 방법 2 — 전용 화면 (`/company-profile`)

상단 메뉴의 "우리 회사 맞춤 찾기"에서 회사 프로필을 여러 개 만들고 관리할
수 있습니다.

- **추가**: 화면 위 양식을 채우고 "저장"
- **수정**: 프로필 카드의 "수정" 버튼 → 양식에 기존 값이 채워짐 → 고쳐서
  "수정 저장"
- **삭제**: 프로필 카드의 "삭제" 버튼 → 확인창 → 삭제(되돌릴 수 없음)
- **매칭 결과 상세 보기**: "이 회사로 매칭 결과 보기" → 전체 지원사업과
  비교한 결과를 항목별 이유와 함께 확인

두 화면 모두 같은 `company_profiles` 표를 보고 있어서, 한쪽에서 저장·수정·
삭제하면 다른 쪽에도 그대로 반영됩니다.

## 입력 항목

소재지, 업종, 창업일(또는 업력 연수), 직원 수, 매출 구간, 중소기업·
소상공인 여부, 수출 여부, 연구개발 여부, 필요한 지원 분야(쉼표로 여러 개
입력 가능).

## 비교 항목과 판정 기준

각 공고를 아래 7개 항목으로 비교해 항목마다 "일치 / 불일치 / 확인 필요"
(지원금액은 "참고")를 매깁니다.

| 항목 | 판정 근거 |
|---|---|
| 지역 | 공고 제목의 `[지역]` 표기와 회사 소재지 비교. 공고에 지역 표기가 없으면 "확인 필요"(전국 대상일 수 있음) |
| 업종·지원분야 | 회사의 업종/희망 지원분야가 공고 제목·분류명에 포함되는지 |
| 업력 | 공고 문구에 "창업 N년 이내" 같은 표현이 있을 때만 회사 업력과 비교 |
| 신청대상 | 공고의 지원대상 문구에 회사 조건(소상공인/중소기업/수출/연구개발/업종)이 언급되는지 |
| 제외대상 | 공고의 제외대상 문구에 회사 조건이 명시적으로 해당하는지 |
| 지원기간 | 접수중/예정/마감임박이면 일치, 마감이면 불일치 |
| 지원금액 | 비교 대상이 아니라 참고용으로만 표시 |

**종합 판정 규칙** (전부 코드로 고정된 규칙이며, AI가 판단하지 않습니다):

1. 하나라도 "불일치"가 있으면 → **조건 불일치**
2. "일치"가 2개 이상이고 지원기간이 "일치"면 → **적합 가능성 높음**
3. 그 외 → **검토 필요**

공고 원문에 없는 정보는 절대 탈락(불일치) 처리하지 않고 "확인 필요"로
남깁니다 — 데이터가 없다는 이유로 기회를 놓치지 않도록 하기 위함입니다.

## 데이터 저장과 보안

- 회사 정보는 이 컴퓨터의 로컬 SQLite DB(`company_profiles` 표)에만
  저장되며, 외부로 전송되지 않습니다.
- 매칭 계산은 이미 저장된 지원사업 데이터(`programs`, `program_fields`,
  원본 응답)만 읽어서 이 컴퓨터 안에서 수행합니다 — 외부 AI API나 토큰을
  전혀 사용하지 않습니다.
- 기존 지원사업 데이터(`programs` 등)는 매칭 기능으로 인해 절대 수정되지
  않습니다 — 회사 프로필을 추가·수정·삭제해도 공고 데이터는 그대로입니다.
- 출처(source)별로 특별 취급하는 코드가 없어서, 나중에 새 출처(NTIS 등)가
  추가돼도 이 로직을 고치지 않고 그대로 적용됩니다.

## 관련 파일

- `app/db/migrations/0006_company_profiles.sql` — `company_profiles` 표 정의
- `app/db/company_matching.py` — 매칭 규칙 엔진
- `app/server.py` — `/company-profile`(목록/추가), `/company-profile/<id>/edit`(수정),
  `/company-profile/<id>/delete`(삭제), `/company-profile/<id>/match`(상세 결과),
  `/programs/profile`(목록 화면 내 저장), `/programs`(사이드바 통합)
- `app/templates/company_profile.html`, `app/templates/match_results.html`,
  `app/templates/list.html`(사이드바)
- `app/db/test_company_matching.py` — 테스트용 회사로 미리보기 실행,
  운영 DB 변경 여부까지 확인하는 테스트 스크립트
