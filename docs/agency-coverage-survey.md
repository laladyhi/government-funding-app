# 기관별 공고 범위 조사 보고서 (Phase 1 확장 검토용)

**조사일**: 2026-09-04
**조사 방법**: 웹 검색(Google/Bing 색인) 및 각 기관 공식 홈페이지 확인. 기관
사이트에 반복 요청이나 크롤링은 하지 않았다. 기업마당 API는 이번 조사에서
**추가로 호출하지 않았고**, 이전에 이미 수집해 로컬 DB에 저장해 둔 20건과,
공개 웹 검색 결과만 사용했다. 새 수집기·크롤러·API 연동 코드는 작성하지
않았다.

**중요한 전제**: "기업마당 사이트에서 검색됨"은 "해당 기관이 과거에 최소
1건 이상 기업마당에 공고를 올린 적이 있다"는 뜻이지, "그 기관의 모든 공고가
빠짐없이, 실시간으로 기업마당에 반영된다"는 뜻이 아니다. 이 둘을 구분해서
읽어야 한다.

## 1. 기업마당 API가 실제로 포함하는 기관·공고 범위

중소벤처기업부의 공식 설명에 따르면, 기업마당은 **중앙부처·지자체·공공기관
등 약 560여 개 지원기관**의 정책정보를 모아 제공하는 통합 포털이다.
[중소벤처기업부 공지](https://www.mss.go.kr/site/smba/ex/bbs/View.do?cbIdx=86&bcIdx=1032140&parentSeq=1032140)

즉 기업마당은 처음부터 **"참여 등록한 기관들의 정보를 모으는 허브"**이지,
대한민국의 모든 정부기관 공고를 자동으로 긁어오는 시스템이 아니다. 각
기관(또는 그 상위부처)이 공고를 기업마당 시스템에 직접 입력/등록해야
노출된다. 이 전제를 확인한 것이 이번 조사의 가장 중요한 결과다.

우리가 실제로 수집한 20건(로컬 DB) 기준으로는 지자체(안산시·성남시·수원시
등), 광역자치단체(경기도·강원특별자치도·충청북도 등), 테크노파크
3곳, 지식재산처 계열 기관 등 **총 15개 기관**이 확인되었다 — 전체
1,542건 중 최신 20건이라는 작은 표본이므로, 이 15개 기관이 기업마당
전체의 기관 구성을 대표하지는 않는다.

## 2. DB 기관 목록 vs 기업마당에서 실제 확인되는 기관 비교

| 구분 | 목록 |
|---|---|
| 현재 로컬 DB에 있는 기관 (20건 표본에서 발견, bottom-up) | 기초자치단체, 경기도, 경기도경제과학진흥원, 강원특별자치도, 강원테크노파크, 충청북도, 포항테크노파크, 전남테크노파크, 전남광주통합특별시, 경상북도, 지방중소벤처기업청, 지식재산처, 한국발명진흥회, 한국지식재산보호원, 직접수행 (총 15개) |
| 설계문서에서 예시로 든 산하기관 (top-down, phase1-mvp-screens.md의 기관구조 예시) | 한국콘텐츠진흥원, 한국관광공사, 영화진흥위원회, 국민체육진흥공단, 중소벤처기업진흥공단, 창업진흥원 (총 6개) |
| 두 목록의 교집합 | **0개** — 20건 표본에는 이 6개 기관의 공고가 하나도 없었다 |

이 결과만 보면 "설계문서의 예시 기관들이 기업마당에서 빠져 있다"는
가설이 그럴듯해 보였다. 그래서 3번 항목에서 이 6개 기관을 개별적으로
직접 조사했다.

## 3. "기관구조에는 있지만 기업마당에서 안 보이는 기관"을 찾기 위한 조사 결과

**결론(예상과 다름)**: 웹 검색(`site:bizinfo.go.kr [기관명]`)으로 확인한
결과, 조사한 6개 기관 **모두 기업마당에 공고를 올린 이력이 확인되었다.**
"완전히 누락된 기관"은 이번 조사 범위에서는 발견되지 않았다. (표본이
20건→6개였을 때는 안 보였지만, 전체 1,542건 범위에서는 존재함)

단, 이건 "검색엔진에 색인된 과거 이력이 있다"는 확인이지, **모든 공고가
빠짐없이 실시간으로 반영되는지, 최신 상태를 유지하는지는 확인하지
못했다** — 이 부분은 "확인 필요"로 남겨둔다.

## 최종 분류

### 그룹 1 — 기업마당 API만으로 우선 운영 가능한 기관·공고
- 한국콘텐츠진흥원, 한국관광공사, 영화진흥위원회, 국민체육진흥공단
- 근거: 4개 기관 모두 기업마당에 공고 게재 이력이 확인되었고, 자체
  Open API는 이번 조사에서 발견되지 않았다(게시판 크롤링만 가능해 보임).
  Phase 1에서는 별도 연동 없이 기업마당 데이터로 이 기관들의 공고를 일부
  커버할 수 있다.
- 남은 리스크: "일부"라는 표현이 핵심이다 — 이 기관들이 올리는 모든
  공고가 기업마당에도 항상 동시에 올라오는지는 확인되지 않았으므로,
  Phase 1 화면에는 "기업마당에서 수집된 공고만 표시 중"이라는 안내가
  필요하다.

### 그룹 2 — 추가 연동 우선순위가 높은 기관
1. **창업진흥원 (K-Startup)** — 이미 별도 Open API가 존재하고, 애초
   로드맵(Phase 3)에도 다음 소스로 계획되어 있었다. 우선순위 1위.
2. **중소벤처기업진흥공단 (KOSMES)** — 이번 조사에서 자체 Open API
   포털(kosmes.or.kr/opendata)이 확인되었고, 기업마당에도 매우 활발하게
   공고를 올리는 기관이라 데이터 품질 비교/보강 목적으로 다음 우선순위로
   검토할 만하다.

### 그룹 3 — 당장은 링크만 관리하고 자동 수집하지 않을 기관
- 한국콘텐츠진흥원, 한국관광공사(투어라즈), 영화진흥위원회, 국민체육진흥공단
  (스포츠산업지원 사이트)
- 근거: 자체 Open API가 확인되지 않아 크롤링이 필요한데, 크롤링은
  유지보수 부담이 크고(사이트 구조 변경 시 깨짐) 이번 조사 지침상
  대량요청도 금지되어 있어 상세 구조를 조사하지 않았다. 지금은 기관명·
  홈페이지·공고 게시판 URL만 기관 DB에 "링크"로 등록해두고, 자동 수집은
  보류한다.

## 조사에서 확인하지 못해 "확인 필요"로 남긴 것들

- 각 기관 게시판의 첨부파일 제공 여부(대부분 있을 것으로 보이나 미확인)
- 한국콘텐츠진흥원·한국관광공사·영화진흥위원회·국민체육진흥공단의
  자체 Open API 존재 여부 — 공공데이터포털에 이름으로 등록된 별도
  데이터셋이 있는지는 이번 조사에서 다루지 않았다(다음 조사 후보)
- 기업마당에 게재되는 공고가 각 기관 전체 공고의 몇 %를 차지하는지
  (전수 비교는 API 재호출 없이는 확인 불가)
- 각 기관 게시판의 robots.txt, 이용약관상 자동 수집 허용 여부(그룹 1/3
  기관을 실제로 연동하기 전에 반드시 확인해야 함)

## 다음 조사 후보 (참고, 아직 미착수)

이번 조사는 문체부·중기부 계열 6개 기관으로 범위를 좁혔다. 원래 설계
문서의 예시(문화체육관광부 산하 기관들)를 기준으로 삼은 것이며, 전체
정부 부처·산하기관 목록을 대표하지 않는다. 다음 조사 대상 후보로는
산업통상자원부 계열(한국산업기술진흥원·KIAT 등), 과학기술정보통신부
계열(정보통신산업진흥원·NIPA 등), 환경부·에너지 계열 기관 등이 있다.
