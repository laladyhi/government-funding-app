# Phase 1 MVP — 화면 설계 (범위 축소 개정판)

> 이 문서는 이전 버전(8개 화면, 로그인·매칭 자리 예약 포함)을 아래 지침에
> 맞춰 축소·개정한 것이다. 데이터 항목의 정확한 정의(어떤 값을 어디서
> 가져오는지)는 [phase1-data-model.md](phase1-data-model.md)를 따른다.
> 이 문서는 그 데이터 모델을 화면에 "어떻게 얇게 얹는지"만 다룬다.

## 개정 원칙

**Phase 1 핵심 흐름은 3단계로만 제한한다.**
`공고를 정확히 수집한다 → 검색·필터한다 → 상세 내용과 출처를 확인한다`

**Phase 1에서 만드는 화면 (4개 핵심 + 최소 보조 3개)**
1. 지원사업 목록
2. 키워드 검색 및 기본 필터 (= 1번과 같은 화면의 기능. 별도 페이지가
   아니라 목록 화면 안의 검색창+필터 패널로 구현한다)
3. 지원사업 상세
4. 원문 공고 및 첨부파일 확인 (= 3번 상세 화면 안의 한 섹션. 별도
   페이지를 만들지 않는다)
5. 최소한의 메인 화면 (검색 진입점만)
6. 기관별 화면 (데이터 검증용, 최소 기능)
7. 기관구조 화면 (데이터 검증용, 최소 기능)

**Phase 1에서 만들지 않는 것 (완전히 후순위, 화면·메뉴 자리조차 만들지
않음)**
로그인·회원가입 / 기업 프로필 / AI 자연어 검색(실제 동작이든 UI
토글이든) / 기업 적합도 계산 / 알림·구독 / 댓글·질문 / 복잡한 통계 /
그래프형 기관 시각화 / 과도한 추천 기능

이전 버전에 있던 "내 회사 등록(준비중)" 헤더 버튼, "AI 검색" 토글,
"비슷한 산업분야 다른 사업" 추천, 마감임박/신규 카드 미리보기 등은
전부 제거한다. 화면 수와 기능을 줄이는 대신, 아래 4개 핵심 화면이
데이터 모델을 정확히 반영하는지에 집중한다.

**공통 헤더 (모든 화면)**
```
[로고 Government Funding AI]   [전체목록/검색]  [기관별보기]  [기관구조]
```
계정 관련 메뉴는 없음 (로그인 기능 자체가 없으므로).

## 1. 지원사업 목록 + 키워드 검색 + 기본 필터 (하나의 화면)

**화면 목적**: Phase 1의 중심 화면. **기업마당(bizinfo.go.kr)에 연계된**
지원사업을 검색어와 필터로 좁혀가며 훑어보고 상세로 진입하는 진입점.
"정부의 모든 지원사업"이 아니라 "기업마당에 등록된 지원사업"이라는 점을
화면 문구·타이틀에서 항상 명확히 한다 (docs/data-source-decision.md 참고).

**목록 카드에 보여주는 정보 (8개로 제한, 그 이상 넣지 않음)**
사업명 / 기관 / 신청기간 / 지원금액 / 대상기업 / 지역 / 공고상태 /
출처배지

> "기관"은 카드에는 주관기관 이름 하나만 표시한다 (예: "한국콘텐츠진흥원").
> 상위 중앙부처가 어디인지는 카드가 아니라 상세 화면 또는 기관별 화면에서
> 확인한다 — 카드 정보량을 늘리지 않기 위함.
> "출처배지"는 이 공고 정보를 어디서 수집했는지 아이콘/짧은 텍스트로
> 표시 (예: "기업마당" 또는 "한국콘텐츠진흥원 자체수집").

**검색 기능**: 검색창 1개 (키워드 입력 → 사업명·기관명·주요 텍스트 대상
단순 텍스트 일치 검색). 자연어 검색 UI는 넣지 않는다.

**필터 기능 (기본만)**
- 산업분야 (다중선택, [phase1-data-model.md](phase1-data-model.md)의
  ClassificationNode 중 산업축)
- 기술분야 (다중선택, 기술축)
- 지역
- 공고상태 (접수중 / 마감임박 / 마감 / 예정)
- 기업규모 (선택)
- 정렬: 마감임박순 / 최신등록순 (그 이상 복잡한 정렬 옵션은 두지 않음)

**버튼**: [검색] [필터 초기화] 카드별 [상세보기]

**사용자 행동**: 검색어 입력 또는 필터 체크 → 목록 즉시 갱신 → 카드
클릭 → 상세 화면 이동

**다른 화면으로 이동**
- 카드 클릭 → 지원사업 상세 화면
- 카드 내 기관명 클릭 → 기관별 화면
- 헤더 [기관별보기] → 기관별 화면(기관 선택 목록)
- 헤더 [기관구조] → 기관구조 화면

**모바일/PC 배치**
- PC: 좌측 고정폭 필터 패널 + 상단 검색창 + 우측 카드 2~3열 그리드
- 모바일: 상단 검색창(고정) + [필터 ⌄] 버튼(누르면 바텀시트) + 카드 1열

**Phase 1 필수**: 8개 필드 카드, 키워드 검색, 기본 필터 5종, 2종 정렬,
페이지네이션(또는 더보기)
**Phase 1 제외**: 적합도순 정렬, AI 검색, 필터 저장/알림 구독, 산업/지원
분야 등 카드 표시 필드 확장

**와이어프레임 (PC)**

## 2. 지원사업 상세 (+ 원문 공고/첨부파일 확인 섹션 포함)

**화면 목적**: 하나의 지원사업을 신뢰할 수 있는 형태로 확인. 핵심 요약을
먼저 보여주고, 이어서 세부 항목을 **항목별 출처와 함께** 보여준다.
"원문 공고 및 첨부파일 확인"은 이 화면의 한 섹션으로 포함된다 (별도
페이지 아님).

**정보 구성 순서**
1. **핵심 요약** (상단 고정/우선 노출): 사업명, 공고상태, 신청기간,
   지원금액, 대상기업, 지역
2. **세부 항목 + 사실 단위 출처** (요청하신 9개 항목, 항목마다 근거 표시):
   지원 대상 / 신청 자격 / 지원 금액 / 신청 기간 / 지원 기간 / 지원 내용 /
   사용 가능한 비용 / 평가 방법 / 제출 서류
   각 항목은 다음 형식으로 표시 (data-model 4번 FactSource 기준):
   ```
   인건비 사용 가능 — 확인된 사실
   출처: 2026년 사업 공고문, p.12   [원문 열기]
   ```
   페이지 특정이 안 되는 웹페이지 출처는:
   ```
   지원 대상: 중소기업(업력 7년 이하) — 확인된 사실
   출처: 한국콘텐츠진흥원 "2026 AI 콘텐츠 제작지원" 공고 페이지
         (수집일 2026.09.01)   [원문 열기]
   ```
   `확인된 사실`이 아닌 항목은 `AI 분석` 또는 `추정` 배지를 반드시 함께
   표시한다.
3. **원문 공고 및 첨부파일 확인 섹션**: 원문 공고 링크(외부, 새 탭),
   첨부파일 목록(파일명 + 다운로드), 각 SourceDocument의 수집일/문서유형
4. **데이터 출처 요약**: 전체 수집 출처 기관, 최초 수집일, 마지막
   업데이트일

**버튼**: [원문 공고 보기] [첨부파일 다운로드] [이 기관의 다른 사업 보기]
[목록으로]

**사용자 행동**: 스크롤 탐색, 각 항목의 [원문 열기] 클릭(원문 내 해당
위치 또는 문서로 새 탭 이동), 기관명 클릭

**다른 화면으로 이동**
- 기관명 / [이 기관의 다른 사업 보기] → 기관별 화면
- [목록으로] → 목록 화면(직전 검색/필터 상태 유지)
- [원문 공고 보기], 각 항목 [원문 열기] → 외부 사이트 또는 첨부파일(새 탭)

**모바일/PC 배치**
- PC: 좌측 70% 본문(세부 항목+출처) + 우측 30% 요약카드(스크롤 고정)
- 모바일: 세로 1단, 핵심 요약을 최상단에 배치해 스크롤 없이 먼저 보이게

**Phase 1 필수**: 9개 세부 항목 전부 + 항목별 FactSource 표시, 원문/
첨부파일 섹션, 전체 출처 요약, 확인상태 배지(확인된 사실/AI분석/추정)
**Phase 1 제외**: 적합도 표시, "비슷한 산업분야 다른 사업" 등 알고리즘
추천, 댓글/질문

**와이어프레임 (PC)**
```

==============================================================

--------------------------------------------------------------
```

## 3. 최소한의 메인 화면

**화면 목적**: 검색으로 가장 빠르게 진입시키는 것 외에는 아무 것도 하지
않는다.

**사용자가 볼 수 있는 정보**: 서비스 한 줄 소개, 검색창, 산업분야 바로가기
칩(선택, 클릭 시 목록 화면으로 이동하며 해당 필터 적용)

**검색/필터 기능**: 검색창 1개 (목록 화면과 동일 컴포넌트)

**버튼**: [검색] [전체 목록 보기]

**사용자 행동**: 검색 또는 산업 칩 클릭 → 목록 화면 이동

**다른 화면으로 이동**: 메인 → 목록 화면 (검색어 또는 산업 필터 적용된 상태)

**모바일/PC 배치**: PC/모바일 모두 세로 1단, 검색창 중심의 매우 단순한
구성. 통계 숫자, 카드 미리보기, 인기 산업 랭킹 등은 넣지 않는다.

**Phase 1 필수**: 검색창, 산업분야 바로가기 칩, [전체 목록 보기] 버튼
**Phase 1 제외**: 통계(전체건수 등), 마감임박/신규 카드 미리보기, 개인화,
로그인 진입점

**와이어프레임**
```
[로고 Government Funding AI]
==============================================================
      우리 회사가 받을 수 있는 정부지원사업을 찾아보세요
      [ 검색창: 예) AI, 로봇, 해외진출...          ] [검색]
      [제조][바이오][AI/SW][콘텐츠][관광][식품][더보기]
                    [전체 목록 보기 →]
==============================================================
[FOOTER: 데이터 출처 안내]
```

## 4. 기관별 화면 (데이터 검증용, 최소 기능)

**화면 목적**: 특정 기관이 운영하는 지원사업을 모아보고, 수집이 정상
작동하는지 눈으로 확인하기 위한 화면. 사용자 편의 기능보다 **데이터
정확성 검증**이 1차 목적이다.

**사용자가 볼 수 있는 정보**
- 기관명, 기관유형, 공식 홈페이지 링크
- 데이터 수집 상태: 수집방식(API/웹크롤링), 마지막 수집일 (data-model
  3번 Organization 기준)
- 이 기관이 ProgramOrganizationRole로 연결된 지원사업 목록 (1번 화면의
  카드 컴포넌트 재사용)

**필터/정렬**: 없음 또는 공고상태만 (최소화). 목록 화면의 필터를 그대로
가져오지 않는다.

**버튼**: [공식 홈페이지 방문] [목록으로]

**사용자 행동**: 사업 카드 클릭 → 상세 화면

**다른 화면으로 이동**: 카드 → 상세 화면 / [목록으로] → 목록 화면

**모바일/PC 배치**: PC/모바일 모두 상단 기관 정보 + 하단 목록 세로 배치
(단순 구조, 별도 레이아웃 최적화 불필요)

**Phase 1 필수**: 기관 기본정보, 수집상태(마지막 수집일), 소속 사업 목록
**Phase 1 제외**: 상위기관 트리 탐색(=기관구조 화면에서 담당), 필터/정렬,
통계 그래프, 팔로우/알림

**와이어프레임**
```
[헤더][<]
==============================================================
한국콘텐츠진흥원 (산하기관)
홈페이지: kocca.kr [방문]
데이터 수집: API 연동 · 마지막 수집 2026.09.04
==============================================================
소속 지원사업 (18건)
--------------------------------------------------------------
[카드][카드][카드]
```

## 5. 기관구조 화면 (데이터 검증용, 최소 기능)

**화면 목적**: 정부→부처→산하기관의 **확인된** 관계만 트리로 보여준다.
[phase1-data-model.md](phase1-data-model.md) 3번의 OrganizationRelationship
중 관계확인상태가 `확인됨`인 것만 표시한다.

**사용자가 볼 수 있는 정보**: 기관명, 기관유형 배지, 소속 사업 건수.
`확인필요`/`추정` 상태 관계는 화면에 표시하지 않는다 (Phase 1은 사용자
화면을 단순하게 유지하고, 미확인 관계 노출 여부는 별도 관리자 도구로
다룬다).

**검색/필터 기능**: 기관명 검색만 (트리 내 검색 → 해당 노드로 스크롤)

**버튼**: [전체 펼치기] [전체 접기] 노드별 [이 기관의 사업 보기]

**사용자 행동**: 노드 클릭 → 펼침/접힘

**다른 화면으로 이동**: 기관명 → 기관별 화면 / [사업 보기] → 목록 화면
(해당 기관 필터 적용)

**모바일/PC 배치**: PC/모바일 동일하게 아코디언(접이식) 세로 트리.
그래프형(노드-화살표) 시각화는 만들지 않는다.

**Phase 1 필수**: `확인됨` 관계만 트리 표시, 기관명 검색, 사업 보기 연결
**Phase 1 제외**: 그래프 시각화, 관계 출처/확인일 등 상세 메타정보의
사용자 화면 노출(필요 시 관리자 도구에서만 확인), 예산 규모 비교

**와이어프레임**
```
[헤더][<]     기관명 검색: [____________]
==============================================================
대한민국 정부
 └ 문화체육관광부                                    [부처]
    ├ 한국콘텐츠진흥원   사업 18건  [보기>]          [산하기관]
    ├ 한국관광공사       사업  9건  [보기>]
    └ ...
 └ 중소벤처기업부                                    [부처]
    ├ 중소벤처기업진흥공단  사업 41건  [보기>]
    └ ...
==============================================================
[전체 펼치기]  [전체 접기]
```
