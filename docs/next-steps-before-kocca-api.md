# 한국콘텐츠진흥원 API 발급 전 다음 단계 (과거 기록)

> 이 문서는 API 승인 전인 2026-09-04의 진행 기록입니다. KOCCA API는
> 2026-09-07에 승인·실제 호출 검증·운영 DB 적재까지 완료되었습니다.

현재 기업마당 API 연결, SQLite 저장 구조, 목록·검색·상세 화면, 데이터 품질 보정과 다기관 연동 구조 준비가 완료되었다.

아래 내용은 승인 전 당시의 계획이며 현재 상태를 설명하는 문서가 아닙니다.

## 1. KOCCA 환경변수 정리

아직 서비스키를 발급받지 않았다면 프로젝트 최상위 `.env`에서 다음 값을 비워둔다.

```env
KOCCA_API_KEY=
```

다음 문구는 API 키가 아니므로 `.env`에 넣지 않는다.

```text
한국콘텐츠진흥원_지원사업공고
```

실제 서비스키를 발급받은 뒤에만 `KOCCA_API_KEY`의 값으로 입력한다.

API 키는 문서, 코드, 채팅, 화면, 로그에 출력하지 않는다.

## 2. Claude Code 확인 요청

다음 내용을 Claude Code에 전달한다.

```text
아직 한국콘텐츠진흥원 API 서비스키가 발급되지 않았으므로 `.env`의 `KOCCA_API_KEY`는 빈 값으로 유지해줘.

현재 상태에서 다음만 확인해줘.

- `KOCCA_API_KEY`가 비어 있으면 외부 API를 호출하지 않는가
- 화면이나 로그에 “승인 대기 또는 키 미설정”으로 표시되는가
- 기업마당 API와 기존 화면은 계속 정상 작동하는가
- 실제 API 키가 발급되기 전에는 KOCCA 관련 테스트가 fixture만 사용하는가

외부 사이트 호출이나 추가 기능 구현은 하지 말아줘.
```

## 3. 현재 앱 직접 확인

로컬 서버를 실행한 뒤 브라우저에서 다음 주소를 연다.

```text
http://127.0.0.1:5000
```

다음 항목을 직접 확인한다.

- 지원사업 목록이 표시되는가
- `AI` 등 키워드 검색이 작동하는가
- 마감임박 필터가 작동하는가
- 공고 상세 화면이 열리는가
- 원문 링크가 정상적으로 열리는가
- 지역을 알 수 없는 공고가 `지역 정보 없음`으로 표시되는가
- 기관을 알 수 없는 공고가 `기관명 미확인`으로 표시되는가
- 출처 배지와 정보없음 배지가 구분되는가
- 목록과 상세 화면의 정보가 서로 일치하는가

불편한 문구나 오류가 있으면 화면을 캡처해 수정 목록으로 기록한다.

## 4. API 발급 전에는 하지 않을 일

- 한국콘텐츠진흥원 실제 API 호출
- 다른 기관 사이트의 대량 크롤링
- PDF·HWP 자동 분석
- AI 요약 및 기업 적합도 계산
- 자동 수집 스케줄링
- 인터넷 배포
- 여러 기관 API를 동시에 추가하는 작업

## 6. API 발급 후 진행 순서

서비스키가 발급되면 다음 순서로 진행한다.

1. `.env`의 `KOCCA_API_KEY`에 실제 서비스키 입력
2. 키 값 자체를 출력하지 않는지 확인
3. 5건 이하의 테스트 API 호출
4. 실제 응답 필드명 확인
5. 기업마당 데이터와 필드 비교
6. 중복 공고 여부 확인
7. 원문 URL과 첨부파일 URL 확인
8. 테스트가 정상일 때만 DB 적재
9. 목록·검색·상세 화면에서 확인
10. 그 후 전체 수집 여부 결정

현재 사용자가 할 일은 `.env`의 잘못된 KOCCA 값을 비우고, 브라우저에서 현재 앱을 사용해보며 개선점을 기록하는 것이다.
