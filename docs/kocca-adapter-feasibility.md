## 결론

### **공공데이터 API 연동 권장**

**근거**
- 게시판을 직접 크롤링하지 않아도 되는 공식 구조화 API(공공데이터포털,
  `data.go.kr/data/15134251`)가 이미 존재하고, 무료·JSON·공공누리
  라이선스로 재사용 조건이 명확하다.
- 응답 필드에 접수시작일/접수마감일이 분리되어 있는 등, 지금 쓰고 있는
  기업마당보다 일부 항목이 더 구조화되어 있다.
- 게시판 크롤링을 택하면 얻는 이점(더 풍부한 본문·이미지 등) 대비, JS
  기반 첨부파일 링크 처리와 HTML 구조 변경 위험이라는 유지보수 부담이
  더 크다.

**보류·유의 사항 (이번 조사에서 끝까지 확인하지 못한 것 — 확인 필요로 남김)**
- 공공데이터포털 서비스키의 **운영단계 심의승인** 소요 기간과 통과 조건
- 이용약관의 포괄조항이 실제로 게시판 열람(크롤링이 아닌 API 경유)에도
  적용되는지 — API를 쓰면 이 우려 자체가 사실상 해소됨
- 첨부파일이 API 응답에 파일 다운로드 URL 형태로 포함되는지 여부(공공
  데이터포털 페이지만으로는 확인 못함 — 서비스키 발급 후 실제 응답을
  봐야 확정 가능)
- RSS(`rss_pims.xml`)는 API 승인이 지연될 경우의 **임시 대안**으로 고려할
  가치가 있으나, 이번 조사에서 과거 이력 제공 범위는 확인하지 못함

**다음 단계 (아직 착수하지 않음, 사용자 승인 후 진행)**
1. 공공데이터포털에서 "한국콘텐츠진흥원_지원사업공고" 서비스키 신청
   (개발단계 자동승인 확인)
2. 승인된 키로 소량(1~2건) 테스트 호출 → 실제 응답 필드·첨부파일 포함
   여부 확인 (이때 비로소 코드 작성 단계로 넘어감)
