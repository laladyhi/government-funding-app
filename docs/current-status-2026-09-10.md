## NTIS

NTIS 국가R&D 과제검색 API 명세서와 HTML 상세 페이지를 확인했습니다.

- 엔드포인트: `https://www.ntis.go.kr/rndopen/openApi/public_project`
- 인증 항목: `apprvKey`
- 검색 항목: `query`, `searchField`, `displayCount`, `startPosition`
- 연결된 내부 항목: 과제번호, 과제명, 연구책임자, 수행기관, 부처, 연구목표, 연구개발내용, 기대효과, 키워드, 연구비, 연구기간
- 승인 상태: 사용 승인 및 공인 IP 등록 완료

## 중소벤처기업진흥공단

공공데이터포털 데이터셋 15157820의 Swagger 명세를 기준으로 연결했습니다.

- 엔드포인트: `https://apis.data.go.kr/1421000/bizinfo/pblancBsnsService`
- 인증 항목: `serviceKey`
- 응답 형식: JSON
- 주요 검색 항목: 분야, 해시태그, 공고번호, 등록일, 수정일
- 주요 화면 항목: 공고명, 공고 URL, 기관, 사업 개요, 신청기간, 지원대상, 신청방법, 문의처, 첨부파일
- 확인 결과: 실제 API 응답 수신 및 100건 운영 DB 반영 완료

## 사용자 실행 방법

### 중소벤처기업진흥공단 공고 갱신

프로젝트 폴더의 `KOSMES_공고_가져와서_앱에_반영.cmd`를 두 번 클릭합니다.

- 특정 분야만 찾으려면 해시태그를 입력합니다. 예: `창업`, `수출`, `금융`
- 전체 공고를 받으려면 아무것도 입력하지 않고 Enter를 누릅니다.
- 완료 후 앱 화면을 새로고침합니다.

### NTIS 과제 갱신

NTIS 활용신청에서 현재 인터넷의 공인 IP를 허용한 뒤 `NTIS_검색하고_앱에_반영.cmd`를 실행합니다.

## 보안 원칙

- 실제 API 키는 프로젝트 최상위 `.env`에만 보관합니다.
- `.env` 파일, 운영 DB, 실제 원본 응답, 로그는 GitHub에 올리지 않습니다.
- API 키를 Markdown, 채팅, 코드, 화면 캡처에 기록하지 않습니다.
- 원문에 없는 지원금액이나 자격조건은 임의로 만들어 표시하지 않습니다.
