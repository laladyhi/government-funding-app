# 로컬 실행 및 테스트 가이드 (Phase 1)

이 문서는 지금까지 만든 것(수집기 → SQLite DB → 웹 화면)을 **내 컴퓨터에서만**
실행해서 눈으로 확인하는 방법이다. 클라우드 계정, 로그인, 배포는 아직 없다.

## 전체 구조 한눈에 보기

```
.env                        ← 기업마당 API 키 (절대 공유 금지)
collector/                  ← 1단계: API에서 원본 데이터 수집 (원본 파일, 절대 수정/삭제 금지)
  fetch_and_store.py           실행하면 기업마당에서 20건을 새로 받아온다
  raw/bizinfo/...              받아온 원본 그대로 (수정 금지)
  mapped/bizinfo_mapped.json   원본을 표준 구조로 변환한 결과
app/
  db/
    migrations/0001_init.sql   DB 표 구조 정의
    migrate.py                 DB(SQLite 파일)를 만들고 표를 생성
    load_bizinfo.py             mapped 결과를 DB에 넣는다 (중복 방지 포함)
  data/govfunding.sqlite3     실제 데이터가 들어있는 DB 파일 (자동 생성됨)
  templates/                  화면 디자인(HTML)
  server.py                   웹 서버 실행 파일
requirements.txt            필요한 프로그램 목록
```

## 0. 최초 1회만: 필요한 프로그램 설치

```bash
pip install -r requirements.txt
```

(이미 Flask, requests가 설치되어 있는 것을 확인했으므로 생략해도 될 수 있다.
에러가 나면 이 명령을 먼저 실행한다.)

## 1. DB 만들기 (표 구조 생성)

```bash
python app/db/migrate.py
```

`app/data/govfunding.sqlite3` 파일이 생기고, 그 안에 표(지원사업, 기관,
분류 등)가 만들어진다. **이미 실행한 적이 있어도 다시 실행해도 안전하다**
(이미 적용된 것은 건너뛴다).

## 2. 수집한 데이터를 DB에 넣기

```bash
python app/db/load_bizinfo.py
```

`collector/mapped/bizinfo_mapped.json`을 읽어 DB에 넣는다. **이미 들어있는
공고는 다시 넣지 않는다** (`pblancId` 기준 중복 방지, 재실행해도 안전).

## 3. 새 공고를 더 수집하고 싶을 때 (선택)

```bash
python collector/fetch_and_store.py
python app/db/load_bizinfo.py
```

첫 번째 명령이 기업마당에서 최신 20건을 새로 받아 `collector/raw`,
`collector/mapped`에 저장하고(기존 파일은 지우지 않고 새 파일을 추가함),
두 번째 명령이 그 결과를 DB에 반영한다.

## 4. 웹 화면 실행

```bash
python app/server.py
```

터미널에 아래와 비슷한 메시지가 뜨면 정상이다.
```
 * Running on http://127.0.0.1:5000
```

이제 웹 브라우저(크롬 등)를 열고 주소창에 다음을 입력한다.

```
http://127.0.0.1:5000
```

**서버를 끄려면** 터미널 창에서 `Ctrl + C`를 누른다. 이 서버는 내
컴퓨터에서만 열려 있으며, 다른 사람이 인터넷으로 접속할 수 없다.

## 5. 확인 체크리스트

브라우저에서 아래를 직접 눌러보면서 확인한다.

- [ ] `/programs`에 접속하면 지원사업 카드 20개가 보이는가
- [ ] 카드에 사업명·기관·신청기간·지원금액·대상기업·지역·공고상태·출처 배지가 보이는가
- [ ] 검색창에 "AI"를 입력하면 결과가 줄어드는가
- [ ] 공고상태/지원분야 필터를 선택하면 결과가 바뀌는가
- [ ] 카드를 클릭하면 상세 화면으로 이동하는가
- [ ] 상세 화면에서 각 항목 옆에 "확인된 사실 / AI 분석 / 추정 / 미추출" 배지가 보이는가
- [ ] "원문 열기"를 누르면 기업마당 실제 공고 페이지가 새 탭으로 열리는가
- [ ] 아직 확보되지 않은 항목(신청자격, 지원기간, 평가방법 등)이 거짓 없이
      "미추출"로 표시되는가 (임의로 채워진 값이 없는가)
- [ ] 브라우저 화면 어디에도 `.env`의 API 키 값이 노출되지 않는가

## 문제 해결

- **한글이 깨져 보인다(터미널)**: 명령 앞에 `PYTHONIOENCODING=utf-8`을
  붙여서 실행한다. 예: `PYTHONIOENCODING=utf-8 python app/server.py`
  (브라우저 화면 자체는 깨지지 않는다 — 터미널 로그만의 문제)
- **포트(5000)가 이미 사용 중이라는 오류**: 다른 프로그램이 5000번을 쓰고
  있는 것이다. `app/server.py` 맨 아래 `app.run(debug=True)`를
  `app.run(debug=True, port=5001)`로 바꾸고 `http://127.0.0.1:5001`로 접속한다.
- **데이터를 완전히 새로 시작하고 싶다**: `app/data/govfunding.sqlite3`
  파일만 지우고 1번, 2번을 다시 실행한다. `collector/raw`의 원본은
  건드리지 않으므로 데이터가 사라지지 않고 그대로 복원된다.

## 지금 단계에서 정상적으로 "비어있는" 것들

다음은 버그가 아니라 Phase 1에서 아직 채우지 않기로 한 부분이다.

- 지원금액: 기업마당 API가 구조화된 금액을 안 주기 때문에 "미추출"로 표시됨
- 신청자격 / 지원기간 / 사용가능한 비용 / 평가방법 / 제출서류: API에 없는
  항목이라 "미추출" + 안내 문구로 표시됨 (공고 원문/첨부파일 분석은 다음 단계)
- 로그인, 기업 등록, AI 매칭, 알림: 이번 범위에 포함하지 않음
