# 추가 지원금·정책 정보 출처

## 이번에 연결한 범위

웹 화면의 `공식 지원금 찾기` 메뉴(`/support-sources`)에서 정부·공공기관의
공식 사이트로 이동할 수 있게 했다. API 키를 요구하거나 로그인해야 하는
사이트에 사용자의 개인정보를 자동으로 보내지는 않는다.

| 출처 | 화면 연결 | 자동 수집 | 비고 |
|---|---:|---:|---|
| 정부24 혜택알리미 | 완료 | 하지 않음 | 개인·가족 맞춤 안내는 정부24에서 직접 로그인해 확인 |
| 기업마당 | 완료 | 기존 연결 | 중소기업·소상공인 지원사업의 현재 기본 출처 |
| K-Startup | 완료 | 일부 연결 | 창업 지원사업 테스트 데이터가 운영 DB에 반영됨 |
| 소상공인24 | 완료 | 하지 않음 | 공식 공개 API 확인 전까지 직접 확인 |
| 고용24 | 완료 | 하지 않음 | 채용·고용 지원제도는 조건에 따라 결과가 달라짐 |
| 중소벤처24 | 완료 | 하지 않음 | 공식 공개 API 확인 전까지 직접 확인 |
| e나라도움 | 완료 | 하지 않음 | 보조금 공고와 신청 절차를 직접 확인 |
| 공공데이터포털 | 완료 | 하지 않음 | 자동 연결할 공식 API를 찾는 출발점 |

## 자동 수집을 추가할 때의 기준

1. 해당 기관이 지원사업 공고용 공식 API를 제공하는지 확인한다.
2. API 이용약관·라이선스·서비스키 승인 상태를 확인한다.
3. 실제 응답을 5건 이하로 테스트한다.
4. 실제 필드명, 상세 URL, 첨부파일 URL을 확인한다.
5. 중복과 화면 표시를 확인한 뒤 운영 DB에 적재한다.

정부24 혜택알리미처럼 개인의 로그인 정보와 맞춤 조건이 필요한 서비스는
공개 공고 수집기와 별도로 취급한다. 공공 사이트의 최종 지원 가능 여부는
각 사업 공고와 담당 기관의 심사를 기준으로 한다.
