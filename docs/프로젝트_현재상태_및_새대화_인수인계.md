# 정부 지원사업 앱 현재 상태 및 새 대화 인수인계

작성 기준일: 2026-09-09

이 문서는 다음 대화창에서 프로젝트 작업을 이어갈 때 먼저 읽어야 하는 현재 상태 요약입니다.

## 1. 앱 실행

프로젝트 폴더의 `앱_실행.cmd`를 더블클릭하면 됩니다.

- Python 앱이 실행됩니다.
- 브라우저가 자동으로 `http://127.0.0.1:5000/programs`를 엽니다.
- 저장된 회사 프로필이 있으면 기본 화면에 맞춤 사업이 먼저 표시됩니다.
- 앱을 다시 실행했는데 화면이 갱신되지 않으면 기존 검은색 명령 창을 닫고 `앱_실행.cmd`를 다시 실행한 뒤 브라우저를 새로고침합니다.

## 3. 현재 화면 기능

- 지원사업 목록·상세 화면
- 출처별 표시: 기업마당, e나라도움, KOCCA, K-Startup, 정부24 혜택
- 보조금 규모, 신청대상, 제외대상, 창업업력, 지원기간, 신청방법 요약
- 지역 검색 및 지원분야·출처·공고상태 필터
- 마감임박·접수중·접수예정·마감 색상 표시
- 회사 프로필 입력 기능
- 회사 조건과 지원사업을 비교하는 맞춤 매칭 기능
- 목록에서 맞춤 사업을 먼저 표시하고, `전체 사업 보기`를 누르면 전체 목록 확인
- 추천 이유 표시
  - 초록색: 일치
  - 노란색: 확인 필요
  - 빨간색: 불일치

## 4. 매칭 로직 현재 기준

외부 AI나 토큰을 사용하지 않는 규칙 기반 비교입니다.

현재 비교하는 정보:

- 지역
- 업종·희망 지원분야
- 신청대상
- 제외대상
- 창업업력
- 지원기간
- 직원 수 기준
- 매출 기준
- 지원금액은 공고에 값이 있을 때 참고 정보로 표시

최근 개선 사항:

- 제목뿐 아니라 `지원분야_대분류`, `지원분야_중분류`, `사업요약`, `대상기업`, 저장된 원문 필드까지 비교
- `제조업/제조기업`, `수출/해외진출`, `연구개발/R&D`, `디지털 전환/스마트공장` 같은 표현을 유사하게 인식
- 공고에 직원 수·매출 기준이 없으면 불필요하게 탈락시키지 않고 `참고`로 표시
- 회사 조건이 많이 일치하고 확인할 항목이 적은 사업을 위로 표시
- 마감일은 적합도가 같은 경우에만 보조 정렬 기준으로 사용

중요한 주의사항:

`일치`는 원문에서 회사 정보와 관련 표현이 확인되었다는 뜻이며, 정부기관의 최종 지원 자격 승인이나 선정 결과를 의미하지 않습니다. 최종 신청 전에는 반드시 원문 공고를 확인해야 합니다.

## 5. 최근 전체 매칭 검증

- 테스트용 회사 프로필은 검증 후 삭제함

## 6. API 연동 상태

### 연동 완료

- 기업마당: 전체 수집 및 저장
- K-Startup: 연동 및 저장
- 정부24 혜택: `serviceList` 및 소상공인 조건 호출 확인 후 저장
- KOCCA: 명세서 PDF와 실제 응답을 확인한 뒤 연동·저장
- e나라도움: 승인된 공공데이터포털 API, 전체 응답 수집·선별·저장

### 아직 연동하지 않은 것

- KOSMES: `.env`에 키가 있어도 API 명세·요청 형식 확인과 어댑터 구현이 아직 필요함
- NTIS: 서버 IP 등록 또는 이용 조건 확인이 필요하며 현재 앱의 지원사업 DB에 정식 적재하지 않음
- 그 밖의 기관은 API 명세와 활용 승인을 확인한 후 별도 어댑터를 추가해야 함

API 키는 프로젝트의 `.env`에만 보관합니다. 대화, 문서, 코드, GitHub에는 입력하지 않습니다.

## 7. 자동 업데이트

자동 업데이트 관련 파일:

- `자동업데이트_설치.cmd`: Windows 작업 예약 등록
- `scripts/install_twice_daily_update.ps1`: 매일 두 번 예약 등록
- `scripts/update_all_sources.py`: 출처별 수집·저장 순서 실행
- `scripts/run_scheduled_update.cmd`: 예약 실행용 진입 파일

예정 시간:

- 오전 09:30
- 오후 15:30

자동 업데이트 대상:

- 기업마당
- K-Startup
- 정부24 혜택
- KOCCA
- e나라도움 API 키가 준비된 경우 e나라도움

KOSMES는 아직 자동 업데이트 대상이 아닙니다.

자동 업데이트가 실제로 등록되었는지는 `자동업데이트_설치.cmd`를 **관리자 권한으로 실행**한 뒤 Windows 작업 예약 등록 결과를 확인해야 합니다. 설치 완료 문구가 나오기 전에는 예약이 등록되었다고 가정하지 않습니다.

## 8. GitHub 공개 원칙

저장소: `laladyhi/government-funding-app`

공개하는 것:

- Python 코드
- HTML/CSS 템플릿
- 테스트 코드
- 가상 fixture

- `.env.example`

- `collector/mapped/` 실제 수집 결과
- `collector/logs/` 실행 로그
- 실제 XML·HTML·PDF 명세 저장본

## 9. 다음 대화에서 먼저 확인할 작업

1. 새 대화에서 이 문서를 먼저 읽습니다.
2. 앱을 실행하고 맞춤 목록·전체 목록·상세 화면을 확인합니다.
3. 자동 업데이트 작업이 실제로 등록되었는지 확인합니다.
4. 사용자가 원하는 경우 KOSMES 또는 NTIS API 명세를 확인합니다.
5. 새로운 변경을 하기 전 운영 DB·API 키·실제 원본 파일을 건드리지 않는지 확인합니다.
