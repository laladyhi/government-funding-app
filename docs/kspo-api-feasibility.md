# 국민체육진흥공단(KSPO) 공고 전용 API 연동 가능성 조사

**조사일**: 2026-09-04
**조사 방법**: 웹 검색 및 공식 페이지(data.go.kr) 열람만 진행. **어댑터 코드,
실제 API 호출, 크롤링, DB 변경은 전혀 하지 않았다.** 확인하지 못한 항목은
추정하지 않고 "확인 필요"로 표시한다.

---

## 핵심 발견

공공데이터포털에 **"스포츠산업지원 지원사업 정보"**라는, 목적에 정확히
부합하는 데이터셋이 실제로 등록되어 있다. 설명에 "공고제목 등의 조회조건을
이용하여 스포츠산업 지원사업에 대한 원하는 데이터를 조회할 수 있음"이라고
명시되어 있어, 이전 조사(2026-09-04, `agency-coverage-survey.md`)에서
"자체 API 미확인"으로 남겼던 판단을 갱신할 근거가 생겼다.

다만 Swagger 상세표(정확한 End Point·파라미터·응답필드 전체 목록)는
자동화된 웹 조회로는 열리지 않았다(브라우저에서 JS로 렌더링되는 부분) —
K-Startup 때와 달리 아직 사람이 직접 열람하거나 다운로드한 가이드 문서가
없어서, 이 부분은 단정하지 않고 "확인 필요"로 남긴다.

## 참고 (혼동 주의)

같은 기관의 유사 데이터셋이 하나 더 있다: **"스포츠산업지원 스포츠산업
정보"**([data.go.kr/data/15107857](https://www.data.go.kr/data/15107857/openapi.do)).
이름상 통계성 정보로 보이며 공고 전용은 아닌 것으로 추정되지만 확실하지
않다 — "확인 필요"로만 남겨두고, 이번 조사 대상(15107780)과 혼동하지 않는다.

## 결론 및 다음 단계

이전에 KSPO를 `연동후보`로 바꿔둔 판단이 근거를 갖게 되었다. 다음 단계는
K-Startup 때와 동일한 순서를 따른다.

1. **Swagger 페이지를 브라우저로 직접 열어** 정확한 End Point·요청
   파라미터·응답 필드 표를 확보한다 (또는 활용신청 후 제공되는 가이드
   문서가 있다면 다운로드).
2. 확보한 명세를 이 문서에 반영해 "확인 필요" 항목을 채운다.
3. 공공데이터포털에서 서비스키 활용신청(자동승인이므로 빠르게 받을 수
   있을 것으로 예상).
4. `.env`에 `KSPO_API_KEY`로 저장 (값은 문서/채팅에 절대 기록하지 않음).
5. 그 다음에야 5건 이하 테스트 호출 → 어댑터 코드 작성 순서로 진행한다.

**아직 어댑터 코드나 실제 호출은 작성하지 않는다** — 위 1~2번(Swagger
명세 확보)이 선행되어야 한다.
