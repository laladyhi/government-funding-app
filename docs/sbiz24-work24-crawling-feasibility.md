# 소상공인24 · 고용24 자동수집(크롤링) 가능성 조사

**조사일**: 2026-09-04
**조사 방법**: robots.txt·이용약관·공개 페이지 열람만 진행. **실제 반복
요청이나 크롤러 코드는 작성하지 않았다.** 아래 결론에 따라 이번에는
어떤 수집 코드도 만들지 않았다.

## 고용24 (work24.go.kr)

1. **robots.txt**: `Allow: /`가 기본이며, `/cm/common/`, `/sa/`, `/ei/`,
   특정 통합검색 페이지만 차단. Bingbot에는 게시판 하나(`selectBbttList.do`)
   추가 차단. Crawl-delay 없음.
2. **이용약관 자동수집 금지 여부 — 명시적으로 확인됨**:
   - 제14조의2: "사전 허락 없이 자동화된 수단을 이용하여 개인정보를
     스크래핑하는 행위", "과도한 트래픽을 유발하여... 시스템 성능을
     저하"하는 행위 제한
   - 제17조: "서비스를 이용하여 얻은 정보를... 사전 승낙없이...
     복제하거나... 제3자에게 제공하는 행위" 금지, "상업적 목적으로
     이용할 수 없습니다"
   - 근거: https://m.work24.go.kr/cm/c/d/0130/retrieveUtzeStpt.do
3. **로그인 없이 보는 목록 URL**: 공지사항 게시판 URL은 찾았다
   (`www.work24.go.kr/cm/c/a/0100/selectBbttInfo.do?...`)이나, 이는
   "사업주 지원사업 공고"가 아니라 사이트 전반 공지사항으로 보인다
   (이전 조사에서도 work24엔 "기업 지원사업 공고" 전용 게시판/API가
   확인되지 않았다).
4. **목록 페이지 구조**: 확인 불가 — 실제로 열어보니 정적 HTML에는
   "공지사항 테이블입니다"라는 빈 틀만 있고 게시글 제목이 하나도 없었다.
5. **JavaScript 필요 여부**: **예** — 게시글 내용이 클라이언트 측
   스크립트로만 로드되는 것으로 보인다.
6. **수집 가능/불가 정보 구분**: 이용약관상 사전 승낙 없는 복제·재배포·
   상업적 이용이 전부 금지되어 있어, 사실상 전체가 "수집하면 안 되는
   정보"로 판단했다.
7. **판정**: 이용약관에 명시적 금지 조항이 있고, 기술적으로도 JS
   렌더링 장벽이 있어 **자동수집을 진행하지 않는다.**

## 소상공인24 (sbiz24.kr)

1. **robots.txt**: `User-agent: Googlebot`만 명시, `Allow: /`,
   `/mypage/ /login/ /join/ /search/ /admin/ /qna/`만 차단. Crawl-delay
   없음. robots.txt 자체는 비교적 허용적이다.
2. **이용약관 자동수집 금지 여부**: **확인하지 못했다** — 검색으로
   구체적 조항 원문을 찾지 못했고, 사이트가 JS로 렌더링되어 이용약관
   페이지 내용을 자동으로 열람하기도 어려웠다. 불확실한 상태로 남긴다.
3. **로그인 없이 보는 공고 목록 URL**: **확인하지 못했다.**
   `www.sbiz24.kr` 메인 페이지를 열람했지만 제목("소상공인24") 외에는
   아무 내용도 반환되지 않았다 — 자바스크립트로 렌더링되는 SPA(단일
   페이지 애플리케이션) 구조로 보인다.
4. **목록 페이지 구조(제목/날짜/상세URL)**: **확인 불가.** 더 중요한
   발견은, 소상공인24가 기업마당처럼 "하나의 통합 공고 게시판"을 쓰지
   않고, **지원사업마다 완전히 별도의 서브도메인 미니사이트**로
   운영된다는 점이다. 예:
   - `credit.sbiz24.kr` (소상공인 부담경감 크레딧)
   - `voucher.sbiz24.kr` (경영안정 바우처)
   - `delivery.sbiz24.kr` (배달택배비 지원, 종료됨)

   즉 "목록을 주기적으로 수집한다"는 접근 자체가 이 사이트 구조와 맞지
   않는다 — 사업마다 URL도, 페이지 구조도, 생애주기(사업 종료 시
   서브도메인 자체가 사라짐)도 전부 다르다.
5. **JavaScript 필요 여부**: 메인 페이지 기준으로는 **필요해 보인다**
   (정적 HTML에 실제 콘텐츠 없음).
6. **수집 가능/불가 정보 구분**: 목록 구조 자체를 확인하지 못해 판단할
   수 없었다.
7. **판정**: 이용약관이 불확실하고, 통합된 목록 페이지가 구조적으로
   존재하지 않는 것으로 보여 **자동수집을 진행하지 않는다.**

## 이번에 하지 않은 것 (판정에 따른 결과)

두 사이트 모두 위 규칙("허용되지 않거나 불확실하면 코드를 작성하지
않는다")에 해당해, 다음 단계(5건 시험 수집, 3초 이상 간격, 표준 구조
변환, 원본 저장·중복 방지, 운영 DB 반영 등)는 전혀 진행하지 않았다.
기업마당·K-Startup 데이터와 운영 DB(25건)는 이번 조사로 전혀 변경되지
않았다.

## 향후 재검토 조건

- **고용24**: 이용약관이 바뀌거나, 한국고용정보원으로부터 별도 서면
  허락을 받는 경우에만 재검토.
- **소상공인24**: 이용약관 원문을 사람이 직접 확인해 명시적 금지가
  없다고 확정되고, 특정 지원사업의 서브도메인 하나를 대상으로 좁혀서
  (전체가 아니라) 재검토하는 것을 권장. 구조상 "전체 자동수집"보다는
  "사용자가 지정한 사업 하나의 상세 페이지만 가끔 확인" 정도가 이
  사이트 구조에 더 맞을 수 있다.
