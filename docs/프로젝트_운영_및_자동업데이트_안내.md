# 정부지원사업 앱 운영 안내

이 문서는 현재 앱의 연결 상태와 사용 방법, 자동 업데이트 방법을 정리한 안내서입니다.

## 1. 현재 연결된 자료 출처

현재 앱에는 다음 5개 출처의 자료를 표시할 수 있습니다.

| 출처 | 현재 저장 건수 | 연결 상태 |
|---|---:|---|
| 기업마당 | 1,552건 | 연결됨 |
| 창업진흥원(K-Startup) | 5건 | 연결됨 |
| 정부24 혜택 | 5건 | 연결됨 |
| 한국콘텐츠진흥원 | 4건 | 연결됨 |
| e나라도움(국고보조금) | 738건 | 연결됨 |
| 합계 | 2,304건 |  |

(2026-09-09 기준. 기업마당은 API가 알려준 전체 건수를 기준으로 전체 수집,
e나라도움은 전체 응답 197,936건 중 공고명·접수기간이 있는 자료만 선별)

API 키의 실제 값은 이 문서에 기록하지 않습니다.

## 2. 앱에서 확인할 수 있는 내용

각 지원사업에서 다음 항목을 요약해 보여줍니다.

- 보조금 규모
- 신청대상
- 제외대상
- 창업업력
- 지원기간
- 지원방법
- 신청기간
- 지원내용
- 원문 상세 페이지

공식 자료에 금액이나 조건이 없으면 임의로 추정하지 않고 `정보 없음` 또는 `공식 원문 확인 필요`로 표시합니다.

또한 "우리 회사 맞춤 찾기" 화면에서 회사 프로필(소재지·업종·업력·직원 수·
매출·수출/연구개발 여부·희망 지원분야)을 입력하면, AI나 외부 API 없이
지역·업종·업력·신청대상·제외대상·지원기간을 규칙으로 비교해 "적합
가능성 높음/검토 필요/조건 불일치"로 분류해 보여줍니다. 공고에 없는
정보는 탈락시키지 않고 "확인 필요"로 남깁니다.

## 3. 출처별로 보는 방법

앱의 지원사업 목록 화면에서 `출처 전체` 선택 상자를 사용하면 다음과 같이 볼 수 있습니다.

- 기업마당만 보기
- K-Startup만 보기
- 정부24 혜택만 보기
- 한국콘텐츠진흥원만 보기
- e나라도움만 보기

지역 입력란에 시·도 이름(예: "경기")을 입력하면 그 지역 공고와 "전국"
대상 공고만 함께 볼 수 있습니다.

검색어, 공고상태, 지원분야와 함께 사용할 수도 있습니다.

## 4. 전체 데이터 수집 기능

기존에는 기업마당 자료를 20건만 가져왔습니다. 현재는 API가 알려주는 전체 건수를 읽어 필요한 페이지 수를 자동 계산하도록 변경했습니다.

- 기업마당: 현재 API가 약 1,542건을 알려주며, 전체 수집 시 약 155페이지를 확인합니다.
- K-Startup: API의 전체 페이지를 확인해 수집할 수 있습니다.
- 정부24: 개인 복지 전체가 아니라 우선 `소상공인` 대상 자료를 전체 수집합니다.
- 한국콘텐츠진흥원: 현재 지원사업 목록을 페이지 단위로 수집할 수 있습니다.

전체 수집은 API 호출량이 많으므로 페이지 사이에 대기 시간을 두고 실행합니다. API가 일시적으로 응답하지 않으면 기존 데이터는 삭제하지 않고 오류 로그만 남깁니다.

## 5. 자동 업데이트

자동 업데이트는 매일 두 번 실행하도록 준비되어 있습니다.

- 오전 9시 30분
- 오후 3시 30분

기관마다 공고를 올리는 시간이 다르기 때문에 정해진 공통 시간은 없습니다. 일반적으로 업무시간인 오전 9~11시와 오후 2~5시 사이에 등록되는 경우가 많아 이 시간으로 설정했습니다.

## 6. 자동 업데이트 설치 방법

아래 파일을 한 번만 실행하면 됩니다.

프로젝트 폴더의 `자동업데이트_설치.cmd`

실행 순서:

1. 위 파일을 찾습니다.
2. 파일을 두 번 클릭합니다.
3. 검은색 창에 `설치가 완료되었습니다.`가 표시되는지 확인합니다.
4. 검은색 창의 아무 키나 눌러 닫습니다.

설치가 완료되면 앱을 계속 켜 두지 않아도 Windows가 정해진 시간에 자료 수집을 실행합니다.

업데이트가 끝난 뒤 앱 화면을 새로고침하면 새 자료가 표시됩니다.

## 7. 자동 업데이트가 실패할 때

API 사이트가 잠시 중단되거나 인터넷 연결이 끊기면 해당 회차의 업데이트가 실패할 수 있습니다.

- 기존 DB 자료는 그대로 유지됩니다.
- API 키는 화면이나 로그에 원문으로 표시하지 않습니다.
- 오류 기록은 다음 폴더에 저장됩니다.

`collector\logs`

다음 자동 실행 때 다시 시도합니다.

## 8. API 키 보안 원칙

- API 키는 채팅창이나 문서에 붙여넣지 않습니다.
- 실제 키는 프로젝트의 `.env` 파일에만 보관합니다.
- `.env` 파일은 GitHub에 올리지 않습니다.
- GitHub 공개 저장소에는 코드와 가상 테스트 자료만 올립니다.
- 운영 DB, API 원본 응답, 백업 파일도 공개 저장소에서 제외합니다.

## 9. 현재 남은 작업

기업마당 전체 수집(1,552건)과 e나라도움 전체 수집(738건)은 2026-09-09에
실제로 실행해 운영 DB에 반영을 완료했습니다. 남은 작업은 Windows 예약
작업(자동업데이트_설치.cmd) 등록뿐입니다 — 등록하면 이후로는 사용자가
직접 실행하지 않아도 매일 두 번 자동으로 최신 자료를 반영합니다.

현재 운영 DB는 다음과 같습니다.

`기업마당 1,552건 + K-Startup 5건 + 정부24 5건 + 한국콘텐츠진흥원 4건 + e나라도움 738건 = 총 2,304건`

이 문서에는 API 키, 개인정보, 실제 API 응답 원문을 포함하지 않습니다.

## 10. 데이터가 앱에 들어오는 전체 흐름

각 출처의 자료는 다음 순서로 처리됩니다.

`공식 API 호출 → 원본 파일 보관 → 내부 공통 형식으로 변환 → 중복 확인 → 운영 DB 저장 → 앱 화면 표시`

### 원본 보관

API에서 받은 자료는 출처별 원본 폴더에 보관합니다.

- 기업마당: `collector\raw\bizinfo`
- K-Startup: `collector\raw\kstartup`
- 정부24: `collector\raw\public_benefits`
- 한국콘텐츠진흥원: `collector\raw\kocca`
- e나라도움: `collector\raw\enara`

원본 파일은 나중에 화면의 요약 내용이 어디에서 나왔는지 확인할 수 있도록 보존합니다. 원본 파일마다 내용 확인용 해시도 계산합니다.

### 공통 형식 변환

기관마다 API 항목 이름이 다르므로 앱 내부에서는 다음과 같은 공통 항목으로 변환합니다.

- 사업명
- 기관명
- 신청기간
- 지원대상
- 지원내용
- 상세 페이지 주소
- 출처별 고유번호

날짜 형식이 불명확하거나 지원금액이 원문에 없으면 임의로 만들지 않습니다.

### 중복 확인

같은 출처의 고유번호와 원본 해시를 비교합니다.

- 같은 자료: 다시 저장하지 않음
- 새 자료: 신규 저장
- 내용이 바뀐 자료: 최신 내용으로 갱신
- 제목이 비슷한 자료: 중복 후보로 표시하되 자동 삭제하지 않음

### 화면 요약

앱은 원본과 DB에 저장된 내용을 바탕으로 다음 항목을 요약합니다.

- 보조금 규모
- 신청대상
- 제외대상
- 창업업력
- 지원기간
- 지원방법

공식 API가 제공하지 않는 내용은 `정보 없음` 또는 `공식 원문 확인 필요`로 표시합니다. 추정한 내용을 확정된 사실처럼 표시하지 않습니다.

## 11. 출처별 수집 로직

### 기업마당

기업마당 응답의 `totCnt`에서 전체 공고 수를 확인하고, 전체 페이지 수를 계산합니다. 현재 확인된 전체 건수는 약 1,542건이며 페이지당 10건이면 약 155페이지입니다.

관련 파일:

- `collector\fetch_and_store.py`: 전체 페이지 수집 및 원본 저장
- `app\db\load_bizinfo.py`: 원본을 운영 DB에 반영

### K-Startup

K-Startup 응답의 전체 건수와 페이지 정보를 확인해 여러 페이지를 수집합니다. 공고 고유번호는 `pbanc_sn`을 사용합니다.

관련 파일:

- `collector\fetch_kstartup.py`: 전체 공고 수집
- `app\db\load_kstartup_real.py`: DB 반영
- `collector\adapters\kstartup_adapter.py`: 공통 형식 변환

### 정부24 혜택

개인 복지 전체가 아니라 `소상공인` 대상 조건으로 자료를 수집합니다. 정부24의 서비스ID를 고유번호로 사용합니다.

관련 파일:

- `collector\fetch_public_benefits.py`: 소상공인 대상 전체 수집
- `app\db\load_public_benefits_real.py`: DB 반영
- `collector\adapters\public_benefits_adapter.py`: 공통 형식 변환

### 한국콘텐츠진흥원

지원사업 목록의 페이지 정보를 사용해 현재 목록을 수집합니다. 게시글 고유번호는 `intcNoSeq`를 사용합니다.

관련 파일:

- `collector\fetch_kocca.py`: 지원사업 수집
- `app\db\load_kocca_all.py`: DB 반영
- `collector\adapters\kocca_adapter.py`: 공통 형식 변환

### e나라도움

전체 응답(약 197,936건, 사업연도 기준) 중 공고명과 접수/공고기간이 모두
있는 자료만 선별해 저장합니다(단순 사업구조 정보는 제외). 원본이 XML
기반이라 값에 `<![CDATA[...]]>` 래퍼가 남는 경우가 있어 별도로 정제합니다.
고유번호는 `DTLBZ_ID`를 사용합니다.

관련 파일:

- `collector\fetch_enara.py`: 전체 수집 및 공고 선별
- `app\db\load_enara_real.py`: DB 반영
- `collector\adapters\enara_adapter.py`: 공통 형식 변환

## 12. 자동 업데이트 기능의 현재 상태

자동 업데이트에 필요한 프로그램은 만들어져 있습니다.

자동 실행 프로그램:

`scripts\update_all_sources.py`

이 프로그램은 다음 순서로 실행됩니다.

1. 기업마당 전체 수집
2. 기업마당 DB 반영
3. K-Startup 전체 수집
4. K-Startup DB 반영
5. 정부24 소상공인 대상 전체 수집
6. 정부24 DB 반영
7. 한국콘텐츠진흥원 목록 수집
8. 한국콘텐츠진흥원 DB 반영
9. (`.env`에 `ENARA_API_KEY`가 있을 때만) e나라도움 전체 수집 및 DB 반영

자동 설치 파일:

`자동업데이트_설치.cmd`

현재 상태를 정확히 구분하면 다음과 같습니다.

- 자동 업데이트 프로그램: **만들어짐**
- 자동 업데이트 설치 파일: **만들어짐**
- Windows 예약 작업 등록: **아직 등록하지 않음**
- 실제 전체 데이터 수집: **완료** (2026-09-09, 기업마당·e나라도움 포함 총 2,304건)

따라서 `자동업데이트_설치.cmd`를 사용자가 한 번 실행해야 Windows 예약 작업이 등록됩니다. 등록이 완료되면 매일 09:30과 15:30에 자동 업데이트가 실행됩니다.

## 13. 자동 업데이트 실패 시 처리

자동 업데이트 중 어느 한 출처에서 오류가 나면 해당 작업을 중단하고 로그를 남깁니다. 기존 DB 자료를 삭제하지 않습니다.

로그 위치:

`collector\logs`

자동 업데이트가 정상적으로 끝나면 다음번 앱 화면 요청 때 DB의 최신 자료가 표시됩니다. 브라우저에 이전 화면이 남아 있으면 새로고침하면 됩니다.

## 14. 공개 저장소와 보안 상태

GitHub 개인 저장소에는 코드와 가상 테스트 자료만 공개합니다.

공개하지 않는 자료:

- `.env`
- API 키
- 운영 DB
- DB 백업
- 실제 API 원본 응답
- 수집 로그
- 개인 컴퓨터 설정 파일

현재 자동 업데이트 관련 새 코드는 아직 GitHub에 커밋하거나 push하지 않은 상태입니다.
