## 지금 해야 할 일

### 1. 현재 연결된 5개 출처 전체 수집 (2026-09-09 최초 실행 완료)

사용자 컴퓨터에서 다음 파일을 두 번 클릭합니다.

프로젝트 폴더의 `지금_전체데이터_업데이트.cmd`

이 작업은 다음을 수행합니다.

- DB 백업 생성
- 기업마당 전체 수집 및 저장
- K-Startup 전체 수집 및 저장
- 정부24 소상공인 대상 전체 수집 및 저장
- 한국콘텐츠진흥원 목록 수집 및 저장
- e나라도움 전체 수집(공고명·접수기간이 있는 자료만 선별) 및 저장
- 앱 화면에 표시할 수 있도록 DB 반영

자료량에 따라 시간이 걸릴 수 있습니다. 검은색 창에 완료 메시지가 나올 때까지 닫지 않습니다.

### 2. 앱 화면 새로고침

수집 완료 후 앱 화면에서 새로고침을 누릅니다.

출처 선택 상자에서 기업마당, K-Startup, 정부24 혜택, 한국콘텐츠진흥원, e나라도움을 각각 선택해 건수를 확인할 수 있습니다.

### 3. 자동 업데이트 등록

전체 수집이 정상적으로 한 번 완료된 뒤 다음 파일을 두 번 클릭합니다.

프로젝트 폴더의 `자동업데이트_설치.cmd`

등록되면 매일 오전 9시 30분과 오후 3시 30분에 자동으로 실행됩니다.

## 자동 업데이트의 현재 상태

- 자동 수집 프로그램: 만들어짐
- 전체 수집 실행 파일: 만들어짐
- 화면 출처 필터: 만들어짐
- Windows 예약 작업: 사용자가 설치 파일을 실행해야 등록됨
- 현재 전체 데이터 최초 수집: 완료 (2026-09-09, 운영 DB 총 2,304건)

## 보안 원칙

- 실제 API 키는 `.env`에만 보관
- API 키를 문서·채팅·GitHub에 기록하지 않음
- 운영 DB·백업·실제 원본 응답은 공개 저장소에서 제외
- API가 제공하지 않는 지원금액·자격은 임의로 추정하지 않음
