# 소상공인24 · 고용24 지원사업 공고 API 연동 가능성 조사

**조사일**: 2026-09-04
**조사 방법**: 웹 검색 및 공공데이터포털(data.go.kr) 공식 페이지 열람만 진행.
**화면 크롤링·무단 스크래핑은 하지 않았다. 이번 조사 결과 코드는 작성하지
않았다** (아래 결론 참고 — 조건 12에 따름).

---

## 결론 먼저

| 사이트 | 지원사업 공고용 공식 API | 판정 |
|---|---|---|
| 소상공인24 (sbiz24.kr) | 확인 안 됨 | **연결 안 함** |
| 고용24 (work24.go.kr) | API 자체는 있으나 "기업 지원사업 공고" 용도는 없음 | **연결 안 함** |

두 곳 모두 **"공식 API 확인 안 됨"**으로 보고한다. 검색 결과나 유사한
이름만으로 존재를 단정하지 않았다.

---

## 1. 소상공인24 / 소상공인시장진흥공단(SEMAS)

소상공인24(sbiz24.kr)는 소상공인시장진흥공단이 운영하며, 이 공단의
Open API는 자체 포털이 아니라 **공공데이터포털(data.go.kr)에 등록되는
방식**임을 확인했다. data.go.kr에서 소상공인시장진흥공단이 제공하는
데이터셋을 찾아본 결과:

| 데이터셋 | 형태 | 내용 |
|---|---|---|
| [상가(상권)정보 API](https://www.data.go.kr/data/15012005/openapi.do) | Open API | 점포명·업종·행정구역·좌표 등 **상권 정보** — 지원사업 공고와 무관 |
| [소상공인상담지도 진흥원 안내](https://www.data.go.kr/data/15133966/fileData.do) | 파일(다운로드) | 상담센터 안내 — 공고 아님, API도 아님 |
| [전국 소공인 특화지원센터 현황](https://www.data.go.kr/data/3060083/fileData.do) | 파일(다운로드) | 지원센터 목록 — 공고 아님 |
| [로컬크리에이터 리스트](https://www.data.go.kr/data/15128085/fileData.do) | 파일(다운로드) | 이미 선정된 기업 명단 — 공고 아님 |

**"지원사업 공고"(신청 접수 중인 사업 목록)에 해당하는 API나 데이터셋은
찾지 못했다.** 상가정보 API는 실존하지만 목적이 완전히 다르다(상권
분석용). 소상공인24 자체 도메인(sbiz24.kr)에도 개발자용 Open API 안내
페이지가 있다는 근거를 찾지 못했다 — 있는 것은 "사업 신청 매뉴얼"
(사람이 사이트에서 직접 신청하는 방법 안내)뿐이었다.

## 2. 고용24 / 한국고용정보원 (work24.go.kr)

고용24는 Open API를 **명확히 제공하고 있다.** 서비스 소개 페이지에서
확인한 전체 목록:

- 국민내일배움카드 훈련과정 / 사업주훈련 훈련과정 / 국가인적자원개발
  컨소시엄 훈련과정 / 일학습병행 훈련과정
- 채용정보
- 정부지원일자리정보
- 구직자취업역량 강화프로그램
- 학과정보 / 직업정보 / 강소기업 / 공통코드 / 심리검사 / 직무정보

이 중 사업주(기업) 대상은 **"사업주훈련 훈련과정"**뿐이며, 이는 "직원을
어떤 훈련과정에 보낼 수 있는가"를 조회하는 API다 — 우리 앱이 다루는
"지원금·보조금 공고"(예: 이차보전, 사업화 지원금 등)와는 성격이 다르다.
**"기업 지원사업 공고"에 해당하는 API는 목록에 없다.**

즉 고용24는 공식 API가 있는 것은 맞지만, **이번 앱에 필요한 종류의
데이터를 제공하는 API는 아니다.**

## 3. 정부24 혜택알리미 (검토만, 연동 안 함)

지시하신 대로 자동 로그인이나 개인정보 수집 기능은 만들지 않았다. 대신
"개인 맞춤 없이 공개된 범위"가 있는지만 확인했다.

**발견**: 공공데이터포털에 [행정안전부_대한민국 공공서비스(혜택)
정보](https://www.data.go.kr/data/15113968/openapi.do)라는, 혜택알리미가
안내하는 "공공서비스 목록" 자체를 다루는 **비식별·공개 API가 별도로
존재한다.** 이건 "내가 받을 수 있는 혜택을 로그인해서 찾아주는" 개인화
서비스가 아니라, "어떤 공공서비스들이 있는지"의 전체 카탈로그로 보인다.

**이번 작업 범위에서는 다루지 않았다** — 지시하신 게 "검토"까지였고,
이 데이터셋이 기업 대상 지원사업과 얼마나 겹치는지(개인/가구 대상
서비스가 대부분일 가능성이 높음) 확인이 더 필요하다. 통합을 원하시면
별도로 이 데이터셋만 다시 조사하는 게 좋겠다.
